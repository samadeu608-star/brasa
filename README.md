# Brasa Nocturna — Website de Alta Gastronomia

Projeto web original desenvolvido com foco em UX/UI Design noturno, tipografia editorial e animações com **GSAP 3 + ScrollTrigger**.

## Estrutura do Projeto
- `index.html` — Página completa do restaurante **Brasa Nocturna** (Hero, Cardápio Interativo, Filosofia do Fogo, Coquetelaria, O Salão e Sistema de Reservas).
- `css/styles.css` — Paleta inspirada em carvão e brasa (`#0D0B0A`, `#F59E0B`, `#EA580C`), tipografia *Cormorant Garamond* + *Plus Jakarta Sans*, navbar fixa com desfoque e grid responsivo.
- `js/main.js` — Animações GSAP de entrada e scroll, alternância dinâmica das categorias do cardápio e validação do formulário de reservas.
